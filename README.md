# 📹 Trinethra CCTV Solutions - Official Website

Security Systems, CCTV Camera Sales, Professional Installation & Servicing Website with Built-in Admin CMS Panel.

## 🚀 Standalone Single-File Architecture (`index.html`)

This website is completely self-contained in a single `index.html` file with:
- **Tailwind CSS CDN** (`https://cdn.tailwindcss.com`)
- **Google Fonts CDN** (Noto Sans Telugu & Plus Jakarta Sans)
- **Embedded WebP Base64 Logo** (no external image folders required)
- **Built-in Admin Panel** (PIN: `001992`)
- **Zero build steps, zero npm, zero dependencies**

---

## 🌐 1. Deploy on GitHub Pages (Free Hosting)

Since the website is a single `index.html` in the root:
1. Push this repository to **GitHub**.
2. Go to your repository **Settings** → **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<repo-name>/`!

---

## ☁️ 2. Deploy on Hostinger (via GitHub Git Deployment)

Hostinger has direct Git integration:
1. Log in to **Hostinger hPanel**.
2. Go to **Advanced** → **Git**.
3. Paste your GitHub repository URL: `https://github.com/<your-username>/<repo-name>.git`.
4. Set branch to `main` and directory to `public_html`.
5. Click **Create / Deploy**.
6. Every time you push a change to GitHub, Hostinger can automatically update your website!
